# Como colocar no meu perfil do GitHub

O GitHub reconhece um repositório como **Profile README** quando o nome do repositório é **exatamente igual** ao seu nome de usuário. No seu caso, o repositório precisa se chamar `william-grassis67`.

1. Acesse [github.com](https://github.com) e faça login.
2. Clique em **New repository** para criar um novo repositório.
3. No campo **Repository name**, digite exatamente: `william-grassis67`
4. Marque o repositório como **Public**.
5. Marque a opção **Add a README file**.
6. Clique em **Create repository**.
7. Dentro do repositório recém-criado, clique em `README.md` e depois no ícone de lápis (**Edit**).
8. Apague o conteúdo padrão e cole o conteúdo do README criado acima.
9. Role até o final da página e clique em **Commit changes**.
10. Acesse `github.com/william-grassis67` (seu perfil) e verifique se o README aparece na página inicial do seu perfil.

> Como o nome do repositório é idêntico ao seu username, o GitHub automaticamente exibe o conteúdo desse `README.md` no topo do seu perfil.

# Como adicionar novas Skills

As skills do seu perfil do GitHub **não são sincronizadas com o LinkedIn** — elas não puxam automaticamente as skills listadas lá. No GitHub, as tecnologias são apresentadas visualmente através de **badges** ou **ícones** dentro do próprio `README.md`, como foi feito nas seções **Tech Stack** e **Skills** acima.

Para adicionar uma nova tecnologia, basta incluir um badge ou ícone na seção correspondente. Exemplos de Markdown prontos para usar:
